# AeroNusaID-Website
AeroNusa ID adalah platform web pemantauan kualitas udara (AQI) dan cuaca real-time wilayah Kalimantan, khususnya Banjarmasin. Menyajikan data polutan PM2.5, kelembapan, suhu, serta kecepatan angin secara intuitif. Dilengkapi portal berita cuaca dan sistem login pengguna untuk akses informasi lingkungan harian yang akurat.
